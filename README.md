# Project

This is a standalone web application built with React and Vite.

## Prerequisites

1. Clone the repository using the project's Git URL.
2. Navigate to the project directory.
3. Install dependencies: `npm install`.
4. Ensure you have Node.js 16+ installed.

## Run Locally

Run the development server:

```bash
npm run dev
```

Open the local URL printed by Vite in your browser.

## Environment Variables

Create a `.env.local` file in the project root to configure environment variables:

```bash
VITE_API_URL=https://api.example.com
```

Refer to `.env.example` or the source code for all available configuration options.

## Build for Production

Build the app for production:

```bash
npm run build
```

The output will be in the `dist/` directory.

## Additional Resources

Refer to the [Vite documentation](https://vite.dev) for more information on the build tool and development server.
